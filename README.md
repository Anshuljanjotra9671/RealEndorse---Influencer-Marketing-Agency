# RealEndorse

Connecting brands with the right influencers.

RealEndorse is an influencer marketing agency that helps brands find relevant influencers for their campaigns and helps influencers connect with brands for sponsorship and collaboration opportunities.

The idea is simple — instead of brands spending hours searching for creators and influencers trying to find sponsorship opportunities, RealEndorse brings both sides together.

## What We Do

We help brands discover influencers who are a good fit for their campaign based on things like:

* Niche and content category
* Audience
* Location
* Engagement
* Platform
* Content style
* Campaign requirements
* Budget

Once the right influencers are identified, we help manage the sponsorship and collaboration process between the brand and the creator.

For influencers, RealEndorse provides opportunities to work with brands that match their content and audience.

The goal is to make influencer-brand collaborations easier for everyone involved.

## For Brands

Brands can use RealEndorse to find creators for their marketing campaigns without having to manually search through hundreds or thousands of influencer profiles.

We help with:

* Influencer discovery
* Campaign planning
* Influencer shortlisting
* Sponsorship coordination
* Campaign communication
* Collaboration management

Whether a brand is looking for a single creator or multiple influencers for a larger campaign, we help find creators based on the campaign requirements.

## For Influencers

RealEndorse helps influencers discover sponsorship opportunities and connect with brands that are relevant to their content.

Creators can potentially get opportunities based on:

* Their niche
* Audience
* Engagement
* Content
* Location
* Platform
* Brand requirements

The idea is to focus on **relevant collaborations**, rather than sending the same sponsorship opportunity to every creator.

## The Matching

One of the main parts of RealEndorse is matching the right influencers with the right brands.

A campaign might require something like:

```text
Category: Fitness
Platform: Instagram
Location: India
Followers: 50K - 500K
Engagement: 3%+
Content: Fitness / Lifestyle
Budget: ₹1,00,000
```

RealEndorse can use these requirements to identify influencers who fit the campaign.

The aim is not simply to find influencers with the biggest follower count.

**The right audience and the right content matter too.**

## Why RealEndorse?

Influencer marketing can be difficult to manage manually.

Brands have to find creators, check their profiles, negotiate sponsorships, coordinate campaigns, and track results.

At the same time, influencers often have to search for brands, send pitches, and find sponsorship opportunities on their own.

RealEndorse is built to make this connection easier.

## Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/realendorse.git
cd realendorse
```

### Install dependencies

```bash
npm install
```

### Environment Variables

Create a `.env` file in the root directory and add the required environment variables.

```env
DATABASE_URL=
AUTH_SECRET=
API_URL=
```

Make sure you check the project configuration for any additional variables that are required.

**Never commit your `.env` file or private API keys to GitHub.**

### Run locally

```bash
npm run dev
```

The application should now be available on your local development server.
